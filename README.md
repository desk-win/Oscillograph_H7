# Oscillograph_H7

基于 STM32H747 双核 MCU 的便携式示波器与逻辑分析仪。

M4 核负责实时数据采集，
M7 核负责波形显示、协议解码、数据存储和固件升级。

## 主要功能

- **双通道示波器**：12 位 ADC 采样，支持触发、预触发历史、9 档时基、
  通道增益调节、峰峰值和频率测量。
- **8 通道逻辑分析仪**：约 20 MSa/s 采样，支持逻辑波形显示、时基缩放、
  窗口滚动和跳变记录。
- **协议解码**：支持 UART、I2C、SPI、CAN，解码结果可在屏幕上查看。
- **触摸屏界面**：基于 TouchGFX，800×480 显示屏，支持触摸操作和编码器调节。
- **数据存储**：可将逻辑分析仪的跳变记录导出为 CSV 文件并保存到 SD 卡。
- **OTA 升级**：支持通过 UART 升级 M7、M4 双核固件，提供 A/B 分区与回滚机制。
- **双核协作**：M4 实时采集数据，M7 通过共享内存和 HSEM 完成搬运、显示与处理。

## 项目结构

| 目录 | 说明 |
| --- | --- |
| `CM4/` | 示波器和逻辑分析仪的底层采集固件 |
| `CM7/` | TouchGFX 界面、波形处理、协议解码、SD 卡存储和 OTA |
| `Common/` | 双核共享配置、通信结构和 OTA 公共代码 |
| `BootLoader/` | 启动引导与固件升级支持 |
| `docs/` | 架构设计、功能说明和开发记录 |
